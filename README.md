# Issa Aljariri - Personal Portfolio

## Description

This is a responsive personal portfolio website created for Issa Aljariri. The webpage serves as a digital resume to highlight technical skills, showcase software development projects, and provide a contact form for professional inquiries.

## Features

- **Dark Mode:** Features a toggle switch allowing users to seamlessly transition between light and dark themes.

- **Responsive Layout:** Built with CSS media queries to ensure compatibility across desktop, tablet, and mobile screens.

- **Visual Enhancements:** Includes smooth HTML scrolling functionality and a continuous floating animation applied to the profile picture.

- **Iconography:** Integrates Font Awesome for aesthetic social media and section icons.

## Included Sections

- **Hero/About:** A welcoming introduction alongside social links (GitHub, LinkedIn, Email) and a profile image.

- **Skills:** A visual grid displaying various programming languages and tools, including C/C++, Python, NumPy, Pandas, Git, Linux, HTML, CSS, JavaScript, MS SQL Server, and Vim.

- **Projects:** A dedicated section linking out to GitHub repositories for specific projects, such as a Machine Learning Framework in C, a Bank Management System, and a C File Compressor.

- **Contact:** A simple form interface allowing visitors to submit their name, email, and a direct message.

## File Structure

- `index.html`: The main HTML document containing the site's structure, text content, and external library connections.

- `sytle.css`: The stylesheet defining the visual presentation, CSS variables for theme management, keyframe animations, and responsive media queries.
